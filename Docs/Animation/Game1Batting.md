# Game1 真人揮棒參考

參考：[JOE是棒球〈3️⃣ 打擊動作解析：蓄力、引棒〉](https://www.youtube.com/watch?v=sZ4nUqtBlFo)。

實際查看的示範重點：

- 約 1:32–1:37：側面屈髖，骨盆向內轉。
- 約 2:10：蓄力時肩膀不應過度旋轉。
- 約 2:54：屈髖後的上身與後側蓄力姿態。

`Game1Batter.cs` 將這些特徵轉成適合現有角色比例的程序動畫：後坐幅度小、雙手在後肩約肩膀高度、球棒接近直立並略往後傾。不是影片動作捕捉或逐幀複製。

引棒：蓄力時雙手稍往捕手方向收（仍保持緊湊，不拉長手臂）；出棒初段由握把（knob）帶著雙手往下朝球走，棒頭留在雙手上方，之後才放平進入擊球區。收棒時雙手高過前肩。

出棒與收棒是遊戲內的銜接設計：骨盆先開、手與棒頭稍後釋放，穿過擊球區後延伸收棒。維持既有的 Swing=0.25 蓄力、0.5 擊球和 0.08 秒出棒至擊球時間。腿部 IK 固定前腳，後腳以腳尖附近為支點轉動、腳跟離地，並略往前腳方向拖，讓後膝能往內往下收，而不是整條腿打直。站距約略寬於肩。

驗證：Unity EditMode 的 `Game1BatterTests` 在八位角色各取 101 個姿勢，檢查握棒距離、前腳位移與重複套用姿勢不累積偏移；另輸出 `Builds/Validation/batting-poses.png`：上排從本壘側看、下排從投手方向看，由左至右為準備、蓄力、髖部啟動（引棒）、擊球、延伸、收棒。
