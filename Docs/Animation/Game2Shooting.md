# Game2 真人投籃參考

參考：[Highlight NBA〈完美的投籃有多少細節？3步全面解析投籃姿勢〉](https://www.youtube.com/watch?v=KEe1P7aJvGk)。

實際查看的示範重點：

- 約 1:10：膝蓋與腳尖朝向籃框。
- 約 2:10：屈髖屈膝蓄力（load your hips），從腳掌向上發力；球舉到投籃側額頭上方，手肘在球正下方，輔助手扶在球側。
- 約 2:30：食指與中指之間對準球的中線。
- 約 3:10：出手後手腕完全下壓，跟隨動作停留。

`Game2Shooter.cs` 把這些特徵轉成程序動畫，疊加在角色原本的 idle/run 動畫上：持球（胸前）→ 下沉（屈膝、球到腰部）→ 舉球點 → 出手（手臂伸直朝上、朝籃框）→ 跟隨（手腕下壓、手停在高處，落地後才淡出）。膝蓋 IK 朝向籃框，雙腳著地時固定不滑動，騰空時腳尖下垂；視線一直看籃框。不是影片動作捕捉或逐幀複製。

時機對應：AI 在 `Sim.SHOT_WINDUP`（0.42 秒）內完成下沉到舉球點；玩家的蓄力條到綠區中心時球剛好舉到頂點，所以「球到頂就放開」就是最佳出手時機。出手瞬間球由指尖平滑銜接到飛行軌跡（0.12 秒）。

驗證：Unity EditMode 的 `Game2ShooterTests` 在八位角色各取 101 個姿勢，檢查出手前雙手與球的距離（誤差 < 3 cm，實測 ≤ 4 mm）、著地時雙腳位移、舉球點高於頭部；另輸出 `Builds/Validation/shooting-poses.png`，三排為 tshirt 側面、tshirt 背面、penguin 側面，由右至左為持球、下沉、舉球點、出手、跟隨。
