# 萌友卡丁車 GP 遊戲指南・攻略

> 賽車｜8 車 3 圈道具賽車：漂移集氣、衝刺魚、香蕉皮、無敵星。

## 遊戲規則

### 比賽
- 8 台卡丁車、3 圈決勝；你從第 5 位起跑。
- 名次：已完賽者依時間，其餘依跑過的距離。
- 你衝線後 3 秒結算；還沒完賽的車以目前速度推估完賽時間排名。
- 每條賽道都會記錄你的最佳時間。
### 賽道
- 海洋城市：抓地 1.0，寬闊彎道，適合新手。
- 冰雪企鵝村：抓地 0.82（結冰），連續髮夾彎，轉向要提早。
- 霓虹夜城：抓地 0.95，大起伏的夜間街道。

## 操作方式

- ↑（W／Z）：油門　↓（S）：煞車
- ← →：轉向
- Shift（或 C）：漂移（轉向時按住）
- Space（或 X）：使用道具
- Esc：離開比賽；G：本指南
### 火箭起步
- 倒數出現 GO 的瞬間正在按油門，就會獲得 1 秒加速。

## 車手資料

### 能力（1.0 為標準）：極速／加速／操控
- 汐音 1.00／1.00／1.00 — 全平均。
- 小冰 0.96／1.12／1.12 — 加速與操控最好，失誤後恢復快。
- 光哉 1.02／0.94／1.04
- 阿翔 1.06／0.90／0.94 — 極速最高，但起步慢、難駕馭。
- 小花 1.00／1.08／0.98
- 書白 0.98／1.00／1.10 — 操控型，冰雪賽道好用。
- 緋音 1.05／1.02／0.92 — 高速型。
- 澪 1.01／0.98／1.06

## 道具

### 道具箱
- 每圈有 4 排道具箱（每排 3 個），被拿走 3 秒後重生。
- 名次越後面，拿到好道具的機率越高。
### 道具
- 衝刺魚：1.6 秒加速（最高速 ×1.35、加速度 ×2）。
- 香蕉皮：丟在車後，誰踩到就打滑 1 秒並失去 65% 速度。
- 泡泡彈：往前追蹤最近的一台車，命中讓它打滑。
- 無敵星：5 秒無敵＋加速，撞到別人會把對方撞飛。
### 機率（第 1 名 → 最後一名）
- 香蕉：權重 3 → 1；衝刺魚：2 → 3；泡泡彈：1.5 → 3；無敵星：0.2 → 2。

## 駕駛攻略

### 漂移迷你加速
- 速度超過一半時，轉向＋按住 Shift 開始漂移。
- 漂移 0.8 秒以上放開：藍色火花，0.8 秒加速。
- 漂移 1.6 秒以上放開：橘色火花，1.4 秒加速。
- 漂移時轉向更靈敏（×1.3），離心力只有一半。
### 路線
- 彎道會把車往外推（離心力 ∝ 彎度 × 速度²），入彎前先往內側靠。
- 衝出路面（兩側紅白路肩外）最高速只剩 45%，盡量別出界。
- 冰雪賽道抓地力低，離心力更強，建議全程用漂移過彎。
### 其他技巧
- 電腦車手有「橡皮筋」：你領先太多時它們會加速，落後太多時會放慢，保持穩定即可。
- 領先時拿到香蕉可以留在手上，看到後方有車逼近再丟。
- 無敵星期間直接撞前面的車，可以一路超車。
