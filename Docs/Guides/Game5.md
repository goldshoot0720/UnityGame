# 萌友格鬥王 遊戲指南・攻略

> 格鬥｜逐格判定格鬥：連段、指令必殺、超必殺，對電腦或雙人。

## 遊戲規則

### 模式
- 單人對戰電腦（簡單／普通／困難），或兩人同鍵盤對戰。
- 三戰兩勝，每回合 99 秒；時間到以剩餘血量比例高者獲勝。
### 系統
- 60 FPS 逐格判定：每招都有發生、持續、收招三段。
- 命中會產生短暫停頓（hitstop），畫面震動代表重擊。
- 連段傷害遞減：每多一擊 −10%，最低 40%。
- 氣條滿 100 可以發動超必殺；打中或被打都會集氣。

## 操作方式

### 1P（單人模式也可用方向鍵）
- 移動：WASD／方向鍵；↑ 跳、↓ 蹲
- 輕拳 J（Z）｜重拳 K（X）｜輕腳 U（C）｜重腳 I（V）
- 必殺技捷徑 L（B）｜超必殺捷徑 O（N）
### 2P
- 方向鍵移動；輕拳 ,（數字鍵1）重拳 .（2）必殺 /（3）
- 輕腳 ;（4）重腳 '（5）超必殺 ]（6）
### 防禦
- 按住「後」＝站立防禦；按住「後＋下」＝蹲防。
- 下段攻擊要蹲防，飛撲等「中段／上段」要站著防。
### 指令技
- ↓↘→ + 拳/腳、→↓↘ + 拳/腳、↓↙← + 拳/腳（依角色）。
- 超必殺：↓↘→↓↘→ + 任意鍵，或捷徑鍵（需滿氣）。

## 角色招式

- 汐音（血 1000）：鯨浪波 ↓↘→+拳（飛行道具）｜超：深海鯨嘯（6 段巨浪）
- 小冰（血 1080，最耐打）：企鵝滑壘 ↓↘→+腳（下段，可鑽過飛行道具）｜超：冰原特快車
- 光哉（血 1000，手長）：知識昇龍拳 →↓↘+拳（發動瞬間無敵，最強對空）｜超：真・博學昇龍
- 阿翔（血 980）：旋風腿 ↓↙←+腳（穿越飛行道具）｜超：疾風大旋風
- 小花（血 900，最快）：三連貓爪 ↓↘→+拳｜超：百裂貓爪亂舞（10 段）
- 書白（血 950）：飛撲貓掌 ↓↘→+腳（中段，要站防）｜超：雪崩飛撲
- 緋音（血 960）：緋焰月輪腳 →↓↘+腳（帶火焰的對空踢）｜超：鈴音・緋焰天舞
- 澪（血 1000）：水月返 ↓↙←+拳（反擊架式，接住攻擊後反打 130）｜超：明鏡止水・連掌

## 基本招式數據

### 站立
- 輕拳 發生 4、傷害 30（可連打）｜重拳 發生 7、傷害 70
- 輕腳 發生 5、傷害 35（可連打）｜重腳 發生 9、傷害 80
### 蹲下
- 蹲輕拳 25｜蹲重拳（升龍型）65，對空好用
- 蹲輕腳 25（下段）｜蹲重腳 掃腿 70（下段、擊倒）
### 空中
- 跳攻擊全部是「中段」，蹲著的對手擋不住。
### 被防禦
- 普通技被防禦 0 傷害；必殺技會削血（25%）。

## 攻略技巧

### 基本連段
- 輕拳 → 輕拳 → 必殺：輕拳、輕腳命中後可以取消接必殺技。
- 蹲輕腳 → 蹲輕腳 → 掃腿：下段連打，逼對手蹲防。
### 攻防
- 對手愛站防：用蹲重腳掃腿。對手愛蹲防：跳起來攻擊或用書白的飛撲。
- 對手跳過來：光哉昇龍拳、緋音月輪腳，或蹲重拳對空。
- 汐音遠距離丟鯨浪波消耗，對手靠近再用蹲攻擊。
- 澪的水月返在對手出招瞬間使用，能反打 130 點大傷害；但被看穿會露出空隙。
### 超必殺
- 超必殺有無敵時間，被壓制時用來「逆轉」。
- 氣條滿時畫面會閃爍提示「超必殺 OK！」。
